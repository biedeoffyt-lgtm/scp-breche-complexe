# SCP : Brèche de Complexe — Site Web Officiel

Site web complet pour le jeu Roblox **SCP : Brèche de Complexe**.

## 🚀 Publication sur GitHub Pages

1. Créer un repo GitHub (ex: `scp-breche-complexe`)
2. Pusher tous les fichiers à la racine
3. Aller dans **Settings → Pages → Branch: main → / (root)**
4. Le site sera disponible sur `https://[username].github.io/[repo-name]`

## 📁 Structure

```
/
├── index.html          — Page principale
├── css/
│   ├── style.css       — Styles principaux
│   └── animations.css  — Effets et animations
├── js/
│   ├── main.js         — Logique principale
│   └── effects.js      — Effets visuels avancés
└── README.md
```

## ✏️ Personnalisation

- **Liens Roblox** : Remplacer `https://www.roblox.com` par le vrai lien du jeu
- **Discord** : Remplacer `https://discord.gg` par l'invitation réelle
- **Stats** : Modifier les `data-target` dans `index.html` (section #stats)
- **Images** : Ajouter de vraies images dans `/img/` et mettre à jour les classes gallery/scp
